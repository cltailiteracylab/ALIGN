PROJECT ALIGN

Built within the AI-LIGNED Lab.

Project ALIGN — AI Literacy Integration and Growth Network — is a project under the AI-LIGNED Lab at UNC Charlotte.

The platform explores how AI literacy resources, classroom support, and interactive learning experiences can be brought together within a shared educational environment.
