# Phase 1 Architecture

The ALIGN AI Literacy Platform currently consists of three primary verticals:

1. AI Literacy Materials Repository
2. Classroom AI Agent (RAG-based)
3. Prompt-to-Game / ChatGPT Interface

Shared platform functionality includes navigation, UI components,
content/data structures, and authentication/SSO.

Community and sign-on-dependent collaboration features are deferred
to a later phase.

The architecture will evolve as requirements and API contracts are refined.
