PROJECT ALIGN · PHASE 1

Platform Architecture.

ALIGN Phase 1 brings together three primary AI literacy verticals supported by a shared platform foundation. The architecture will evolve as requirements and API contracts are refined.

PHASE 1 PLATFORM

Three verticals. One shared foundation.

Each vertical addresses a distinct part of the AI literacy experience while sharing common platform capabilities.

01

AI Literacy Materials Repository

Content sources, curation and tagging, repository storage, discovery interfaces, and resource handoff.

+
02

Classroom AI Agent

Knowledge-base retrieval, RAG processing, classroom assistance, user interaction, and responsible-use guidance.

+
03

Prompt-to-Game

Prompt input, generation logic, LLM orchestration, generated learning experiences, and review/edit/save.

SHARED PLATFORM LAYER

Common capabilities connect every vertical.

The three Phase 1 verticals are supported by shared navigation, user-interface components, content and data structures, and authentication/SSO capabilities.
